每个阶段对应课程的一个 lab。读完讲义、跑完示例、做完练习，你应该能看懂那个 lab 的指导书在要你做什么，以及为什么要这样做。

写给零基础的同学：不假设你学过操作系统，C 和 RISC-V 汇编也从需要的地方讲起。这不是课程官方材料，也不是 lab 的答案；练习都在自己电脑上完成，帮你读懂 lab 在要求什么。

<Aside type="note" title="获取代码">

示例和练习要在自己电脑上跑。克隆仓库，或者在每个阶段页面顶部下载该阶段的压缩包。压缩包里只有示例和练习，想要参考答案就克隆仓库：

```sh
git clone https://github.com/sudoyc/ecnu-oslab-guide.git
cd ecnu-oslab-guide/01-lab1-boot/exercise/printf && make
```

需要 Linux 或 macOS（Windows 用 WSL）和 `gcc`。RISC-V 工具链的安装见 [Lab0](/00-lab0-env/) 第 2 节。

</Aside>

<Aside type="note" title="怎么用这套讲义">

1. 先读阶段的讲义页面，遇到“动手”框就去跑对应的示例。
2. `examples/` 是看的：跑一下，观察输出，不用改。
3. `exercise/` 是做的：补完 TODO，`make` 看到全部 PASS 就算过关。
4. 卡住超过半小时再看参考答案。答案不放在网站上，也不在压缩包里，只在 [GitHub 仓库](https://github.com/sudoyc/ecnu-oslab-guide) 每个阶段的 `solution/` 目录里，用上面的 `git clone` 克隆下来就有。看完合上，自己再写一遍。
5. 最后回到课程仓库，做真正的 lab。练习只帮你理解，不是 lab 的答案。

</Aside>

## 课程路线

| 阶段 | 实验 |
| --- | --- |
| 基础设施 | Lab1 机器启动 · Lab2 内存管理 · Lab3 中断与异常 |
| 进程系统 | Lab4 第一个用户进程 · Lab5 系统调用与用户虚拟内存 · Lab6 调度与生命周期 |
| 文件系统 | Lab7 磁盘与缓冲 · Lab8 inode/dentry/path · Lab9 文件管理与整合 |
| 硬件扩展 | Lab10 移植到 VisionFive 2 开发板 |

两次检查：Lab1–3 一次，Lab1–9 一次。检查内容是 Git 提交记录、每个 lab 的 README 文档、代码能否通过测试。
